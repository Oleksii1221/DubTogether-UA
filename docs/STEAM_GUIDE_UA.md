# Steam-посібник: український переклад Dub Together

Цей файл містить готові назви й тексти розділів для публікації в посібнику
Steam. Кожен блок після рядка **Текст розділу** потрібно вставити в окремий
розділ редактора Steam.

## Загальна інформація про посібник

**Назва:**

```text
Український переклад Dub Together — встановлення крок за кроком
```

**Опис:**

```text
Неофіційний український переклад Dub Together для Windows.

Посібник показує, як завантажити та встановити українізатор, скопіювати
створений інсталятором параметр запуску в Steam і запустити гру українською.

Інсталятор не перезаписує оригінальні файли гри та проводить користувача
через усі кроки. Автор перекладу та інсталятора — Kico.

[url=https://oleksii1221.github.io/DubTogether-UA/]Завантажити українізатор[/url]
```

**Категорія:** `Modding or Configuration`

## Розділ 1. Перед початком

**Назва розділу:**

```text
1. Перед початком
```

**Текст розділу:**

```text
[h1]Перед початком[/h1]

Переклад встановлюється окремим файлом і не перезаписує оригінальний
DubTogether.exe або інші файли в каталозі Steam.

[b]Перед встановленням:[/b]
[list]
[*]збережіть свій прогрес у грі;
[*]залиште Steam запущеним;
[*]закрийте вікна, які можуть заважати роботі інсталятора;
[*]переконайтеся, що Dub Together встановлена через Steam.
[/list]

Після звичайного оновлення гри переклад може тимчасово перестати працювати.
У такому разі дочекайтеся сумісної версії українізатора.
```

## Розділ 2. Завантаження інсталятора

**Назва розділу:**

```text
2. Завантаження інсталятора
```

**Текст розділу:**

```text
[h1]Завантаження[/h1]

1. Відкрийте сторінку українізатора:
[url=https://oleksii1221.github.io/DubTogether-UA/]Dub Together UA[/url].
2. Натисніть [b]«Встановити для Windows»[/b].
3. Відкрийте завантажений файл [b]DubTogether-UA-Installer.exe[/b].

Якщо Windows SmartScreen показує повідомлення про невідомого видавця,
натисніть [b]«Докладніше»[/b], перевірте назву файла й виберіть
[b]«Виконати»[/b]. Це повідомлення з'являється через відсутність платного
сертифіката цифрового підпису.

Інсталятор безкоштовний. Завантажуйте його лише з офіційного сайту або
сторінки релізів GitHub.
```

## Розділ 3. Встановлення перекладу

**Назва розділу:**

```text
3. Встановлення перекладу
```

**Текст розділу:**

```text
[h1]Встановлення[/h1]

Після відкриття інсталятора гра не закривається автоматично.

1. Натисніть [b]«Почати встановлення»[/b].
2. Прочитайте попередження. Перед продовженням збережіть прогрес у грі.
3. Підтвердьте встановлення. Лише після підтвердження інсталятор попросить
   Dub Together коректно завершити роботу.
4. Дочекайтеся завершення всіх етапів.

Інсталятор знайде гру у бібліотеках Steam, перевірить сумісність і створить
файл перекладу в локальній теці користувача. Оригінальні файли гри не
змінюються.

Якщо гра не завершить роботу протягом 20 секунд, інсталятор зупиниться й
попросить закрити її вручну. Після цього запустіть встановлення ще раз.
```

## Розділ 4. Параметр запуску Steam

**Назва розділу:**

```text
4. Додавання параметра запуску в Steam
```

**Текст розділу:**

```text
[h1]Останній обов'язковий крок[/h1]

Після встановлення програма покаже готовий рядок, який починається з
[b]--main-pack[/b].

[b]Не копіюйте приклад з інтернету або цього посібника.[/b] Шлях до файла
перекладу створюється окремо для кожного користувача. Натисніть
[b]«Копіювати»[/b] саме у вікні інсталятора.

Далі у Steam:
[list]
[*]відкрийте [b]Бібліотеку[/b];
[*]знайдіть [b]Dub Together[/b];
[*]натисніть шестерню праворуч і виберіть [b]«Властивості»[/b];
[*]у розділі [b]«Загальні»[/b] знайдіть поле [b]«Параметри запуску»[/b];
[*]вставте весь скопійований рядок без додаткових символів.
[/list]

Лапки навколо шляху потрібно залишити. Після вставлення просто закрийте
вікно властивостей — Steam збереже параметр автоматично.
```

## Розділ 5. Перший запуск

**Назва розділу:**

```text
5. Перший запуск українською
```

**Текст розділу:**

```text
[h1]Запуск гри[/h1]

1. Поверніться до інсталятора й натисніть [b]«Готово»[/b].
2. Запустіть Dub Together через Steam.
3. Якщо гра не обрала українську автоматично, відкрийте налаштування мови й
   виберіть [b]«Українська»[/b].

Якщо меню, підказки та елементи інтерфейсу відображаються українською —
встановлення завершено.

Грайте українською 💙💛
```

## Розділ 6. Якщо переклад не запустився

**Назва розділу:**

```text
6. Вирішення проблем
```

**Текст розділу:**

```text
[h1]Вирішення проблем[/h1]

[b]Гра запускається без перекладу[/b]
[list]
[*]перевірте, чи вставлено весь рядок --main-pack разом із лапками;
[*]скопіюйте рядок з інсталятора ще раз;
[*]переконайтеся, що параметр додано саме до Dub Together;
[*]повторно запустіть інсталятор і пройдіть установлення.
[/list]

[b]Інсталятор не знайшов гру[/b]
[list]
[*]переконайтеся, що гра встановлена через Steam;
[*]запустіть Steam і повторіть спробу;
[*]перевірте цілісність файлів гри у властивостях Steam.
[/list]

[b]З'явилося повідомлення про несумісну версію[/b]

Гра могла оновитися. Не намагайтеся підміняти файли вручну — дочекайтеся
оновленої версії українізатора.

Повідомити про проблему можна тут:
[url=https://github.com/Oleksii1221/DubTogether-UA/issues]GitHub Issues[/url].
```
